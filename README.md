Simple Calculator for CodeOrbit Internship Task1
Simple Calculator

📝 Description

A simple command-line calculator developed using Python. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

🛠️ Technologies Used

- Python 3
- Functions
- Conditional Statements
- User Input
- Exception Handling

▶️ Instructions

1. Open the project in VS Code or any Python IDE.
2. Run the program using:

python simple_calculator.py

3. Select the required operation.
4. Enter the numbers when prompted.
5. The program will display the calculated result.
